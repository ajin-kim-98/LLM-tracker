# 윈터딜 PRD

## 해결하려는 문제 (출시 소식 3문장)

- 겨울옷을 사려는 사람은 이제 패딩과 겨울옷 할인 소식을 한 페이지에서 최신순으로 볼 수 있다.
- 예전에는 뽐뿌와 뉴스를 따로 들어가 일일이 찾아야 했지만,
- 윈터딜은 15분마다 새 글을 모아 내가 정한 브랜드와 품목의 할인 소식만 골라 보여준다.

## 누구를 위한 것인가

- 나 (올겨울 입을 패딩을 할인할 때 사고 싶은 사람)

## 핵심 기능 (3개 이내)

1. 뽐뿌 핫딜과 Google 뉴스에서 새 글을 15분마다 모은다.
2. 제목에 내 키워드가 하나라도 있는 글만 남긴다. 뉴스는 제목에 '할인', '세일', '특가' 중 하나가 함께 있어야 한다.
3. 제목, 출처, 가격, 게시 시각, 링크를 최신순으로 보여준다.

## 선택 기능

- **AI로 겨울옷 할인만 보기**: 버튼을 누르면 Chrome 내장 AI(on-device)가 각 글이 겨울옷 할인인지 판단해, 아닌 글(예: 요금제 특가, 실적 기사)을 목록에서 숨기고 판단 이유를 한 줄로 보여준다.
  - 데스크톱 Chrome 148 이상에서만 동작한다. 다른 브라우저에서는 안내 문구만 보이고 기존 기능은 그대로 쓴다.
  - 판단은 사용자의 브라우저 안에서만 하고, 결과는 그 브라우저에만 저장한다. 15분 수집(GitHub Actions)에서는 AI를 돌리지 않는다.
  - 가격은 여전히 수집한 제목의 값만 보여준다. AI가 답한 가격은 화면에 쓰지 않는다.
  - 판단 기준은 `site/ai/prompt.md`에 적는다.

## 추적할 키워드

- 유니클로
- 노스페이스
- 무신사
- 패딩

## 제외 요소

- 로그인
- 댓글
- 공유 기능
- 쇼핑몰 가격 직접 추적
- 최저가 비교
- 알림

## 완료 기준

- **Given** 핫딜 3건, 뉴스 2건 중 내 키워드에 맞는 할인 소식이 3건일 때
- **When** 내 페이지 주소로 들어가면
- **Then** 그 3건만 최신순으로 제목, 출처, 가격, 링크와 함께 보인다.
- **원문에 없는 정보(가격, 할인 폭 등)**: 제목에 가격이 없으면 지어내지 않고 "가격 정보 없음"으로 표시한다.
